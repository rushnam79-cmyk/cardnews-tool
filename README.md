# 카드뉴스 체험판

기사 글을 넣으면 제목 후보 5개, 인스타 본문, 카드 이미지를 만들어 주는 웹 프로그램입니다.

## 쓰는 법
1. `index.html`을 크롬 등 브라우저로 엽니다. 설치는 필요 없습니다.
2. "예시 카드"로 먼저 써 보거나, 글감을 붙여 넣고 "만들기"를 누릅니다.
3. 편집 화면에서 제목, 배경(템플릿/내 사진), 글꼴, 글자색, 테두리를 바꿉니다.
4. "이미지 저장"으로 PNG를 받고, "본문 복사"로 글을 복사해 인스타에 올립니다.

## 글 만들기(AI)를 쓰려면
- Anthropic API 키가 필요합니다. 입력한 키는 이 브라우저에만 저장됩니다.
- 키가 없어도 예시 카드와 직접 쓰기로 카드를 만들 수 있습니다.

## 주의
- 기사 문장을 그대로 옮기지 말고, 기사 사진은 허락 없이 쓰지 마세요.
- 본문의 숫자와 사실은 기사 원문과 맞춰 보고 올리세요.
